## ⚖️ Сравнение компонентов

Экран сравнения построен по принципу детального сравнения характеристик.

### Интерфейс

- **Шапка товара** — иконка категории фланкирована стрелками `◀ / ▶` для переключения между товарами. Под стрелками — счётчик позиции «1 из N»
- **Название и цена** — отображаются под иконкой
- **Кнопка «Удалить»** — убирает товар из сравнения прямо из шапки

### Механики

| Элемент | Поведение |
|---------|-----------|
| 🟠 **Оранжевая точка** | Появляется у названия характеристики, если значения у товаров отличаются |
| 🟢 **Зелёная подсветка** | Выделяет лучшее числовое значение (для TDP/мощности — меньше лучше) |
| **Toggle «Только различающиеся»** | Скрывает строки с одинаковыми значениями; рядом — счётчик отличий |
| **Группы характеристик** | Параметры разбиты по секциям: Общие, Производительность, Память, Экран, Интерфейсы и др. |
| **Сворачивание секций** | Нажатие на заголовок секции сворачивает/разворачивает группу |
| **❓ Подсказка** | Иконка `?` у сложных терминов открывает диалог с пояснением |
| **Навигация стрелками** | При трёх и более товарах в категории — стрелки активны, листают слот независимо |

## 🖥️ Сравнение сборок

При сравнении двух готовых сборок накопители сопоставляются **по типу**, а не по позиции.

### Как работает сопоставление накопителей

| Тип | Определяется по |
|-----|----------------|
| **NVMe SSD** | Наличие ключа `NVMe: Есть` или `PCIe` / `NVMe` в интерфейсе |
| **SSD SATA** | Интерфейс SATA без скорости вращения |
| **HDD** | Наличие характеристики «Скорость вращения шпинделя» |

**Пример:** Сборка A `[NVMe 2TB, HDD 4TB]` vs Сборка B `[NVMe 512GB, SSD 1TB, HDD 2TB]`:

| Строка | Сборка A | Сборка B |
|--------|----------|----------|
| NVMe SSD | Samsung 990 Pro 2TB | WD SN850X 512GB |
| SSD SATA | *Нет в сборке* | Crucial MX500 1TB |
| HDD | Seagate 4TB | Seagate 2TB |

Если один из слотов пустой — отображается «**Нет в сборке**».  
Несколько дисков одного типа нумеруются: **NVMe SSD 1**, **NVMe SSD 2** и т.д.
